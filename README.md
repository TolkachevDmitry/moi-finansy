# Мои финансы — личное PWA-приложение

Статическое веб-приложение для iPhone: расходы, доходы, переводы между **картой** и **накопительным счётом**, лимит расходов, аналитика и JSON-резервные копии.

## Быстрый запуск на iPhone с GitHub Pages

1. Создай репозиторий на GitHub, например `moi-finansy`. Для бесплатного GitHub Pages проще использовать **публичный** репозиторий. Публичен только программный код, **не финансовые операции**.
2. Загрузи **содержимое этой папки** в корень репозитория (не клади всё в дополнительную вложенную папку). Должны быть `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` и каталог `icons`.
3. На странице репозитория открой **Settings → Pages**; в **Build and deployment → Source** выбери **Deploy from a branch**, ветка **main**, папка **/(root)**, **Save**.
4. После публикации открой `https://ТВОЙ-ЛОГИН.github.io/moi-finansy/` в **Safari** на iPhone.
5. Нажми **Поделиться** → **Добавить на экран «Домой»** (в зависимости от версии iOS пункт может находиться в меню действий) → **Добавить**.
6. Запусти через значок «Финансы» и зайди в **Настройки**, чтобы задать начальные остатки. После этого записывай операции.

Можно использовать другой HTTPS-хостинг для статических сайтов. GitHub Pages не требует сервера или базы данных. Для локальной проверки на компьютере: `python -m http.server 8000` и открыть `http://localhost:8000` (установка PWA на iPhone требует HTTPS).

## Как считаются деньги

- Остатки карты и накопительного — это **начальные** значения до внесённых операций, а не текущие остатки, если операции уже введены.
- Доход увеличивает баланс счёта, расход уменьшает.
- Перевод уменьшает баланс исходного и увеличивает баланс целевого счёта; в месячные расходы или доходы он **не попадает**.
- Вводятся суммы в рублях, внутри хранятся **целые копейки** для точности.
- Для импорта прошлых расходов установи начальные остатки на **дату начала истории**. Если не уверен, удобнее установить текущие остатки и начать учёт с сегодняшнего дня.
- Пустое приложение специально **не содержит вымышленных операций и балансов**.

## Безопасность и резервные копии

- Нет сервера с финансовыми данными, регистрации, сторонних аналитик, отправки покупок в сеть, CDN или подключения к банку.
- Данные находятся в `localStorage` **конкретного браузера/установленного веб-приложения** на устройстве.
- **Важно:** Safari и PWA могут иметь разные хранилища. Добавь приложение на домашний экран **до начала учёта** и открывай его через иконку. Данные Safari автоматически не обязательно появятся в установленной копии.
- Очистка данных браузера, удаление приложения, сброс устройства и некоторые системные механизмы очистки хранилища могут удалить историю.
- **Сохраняй резервную копию минимум раз в неделю**: **Настройки → Сохранить копию**, сохрани `.json` в приложение «Файлы»/iCloud Drive/другое безопасное место.
- **Восстановить** полностью заменяет существующую историю данными из выбранного JSON-файла; перед этим рекомендуется экспортировать текущую.
- JSON-файл **не зашифрован** и содержит финансовые сведения. Защищай доступ к нему.
- Сам сайт с кодом может быть публичным, но данные пользователя в репозиторий не загружаются. Не добавляй туда экспортированный JSON.

## Возможности версии 1.0

- Баланс карты / накопительного / общий
- Три вида операций, редактирование и удаление
- Быстрая запись «430 кофе и печенье» с **подтверждением** в форме
- Категории трат и поступлений
- Фильтрация истории по месяцу, типу и строке поиска
- Статистика категорий и столбики по 6 месяцам
- Общий месячный лимит и цель накоплений
- Экспорт / импорт JSON
- Работа офлайн после первой загрузки и установки
- Адаптивный тёмный интерфейс

## Структура

- `index.html` — разметка, экран приложения, диалог операций
- `styles.css` — стили
- `app.js` — логика учёта и сохранения
- `sw.js` — офлайн-кэш ресурсов интерфейса
- `manifest.webmanifest` — настройки установки
- `icons/` — иконки iPhone / PWA

## Ограничения

- Только два счёта и рубли.
- Нет синхронизации между устройствами, облачной резервной копии, PIN-кода или автоматического импорта операций из банка.
- Нет надёжного защищённого хранилища: для долгосрочного хранения данных нужны регулярные резервные копии.
- Обновление PWA может потребовать перезапуска приложения или очистки кэша. **Не очищай данные сайта**, чтобы принудительно обновить приложение.
